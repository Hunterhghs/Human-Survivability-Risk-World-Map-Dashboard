# Human Survivability Risk — World Map Dashboard (2000–2500)

Interactive world map dashboard simulating uninhabitable zone expansion driven by rising temperatures and pollution. Tracks 26 global regions across 23 countries from 2000 to 2500.

**Data model:** Survivability Index (SI) integrating wet-bulb temperature, PM2.5 pollution, water scarcity, poverty, and adaptive capacity.

**Key metrics:**
- Global average SI tracking
- % land rendered uninhabitable
- Population trajectory from 2.7B → extinction-level
- Cumulative excess mortality
- Per-region drill-down with full SI breakdown

Built by [H Heuristics](https://hheuristics.com).
